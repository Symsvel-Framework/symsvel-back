# Responsabilités documentaires des interfaces

| Dépôt | Documentation |
| --- | --- |
| `symsvel-bo` | Mécanismes natifs du BO |
| `symsvel-app` | Mécanismes natifs de l'App |
| `symsvel-front` | Mécanismes natifs du Front |
| Chaque module | Pages, composants, API et comportements qu'il fournit |

Les mécanismes communs sont documentés à leur source, sans duplication dans chaque module. L'assemblage documentaire peut ensuite réunir les contenus dans MkDocs.

La structure et la navigation MkDocs seront traitées séparément ; cette répartition ne préjuge pas de leur implémentation.
