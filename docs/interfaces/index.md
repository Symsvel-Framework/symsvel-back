# Interfaces BO, App et Front

Les trois interfaces utilisent SvelteKit avec des builds statiques. Le BO accompagne le Back ; App et Front sont optionnels.

La documentation générale des mécanismes natifs appartient à chaque dépôt d'interface : fetch et client API, normalisation, i18n, routage, configuration et gestion des erreurs, lorsqu'ils sont implémentés.

Les modules documentent les pages, composants et fonctionnalités qu'ils ajoutent aux interfaces concernées. Aucun comportement non encore livré ne doit être présenté comme opérationnel.

Voir [répartition documentaire](documentation.md).
