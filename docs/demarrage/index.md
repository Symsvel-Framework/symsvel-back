# Premiers pas

La CLI SymSvel est le point d'entrée des opérations de développement et de maintenance.

Prérequis : PHP 8.4 ou supérieur, Composer et Git ; Node.js et npm pour les interfaces. Symfony CLI est facultative.

```bash
symsvel doctor
symsvel --version
symsvel --help
```

Voir [l'installation](installation.md).
