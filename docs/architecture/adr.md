# Décisions d'architecture

Les ADR de référence sont versionnées dans [`docs/adr/`](../adr/README.md), sans duplication dans les autres dépôts.

Les ADR 0000 à 0010 couvrent les principes fondateurs, la séparation framework/modules, les modules natifs, le routage, le Setup, la sécurité, les versions, les données, la récupération et la qualité documentaire.

Une ADR expose une décision ; les pages opérationnelles documentent les mécanismes réellement disponibles.
