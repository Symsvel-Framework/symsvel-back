# Comprendre SymSvel

SymSvel fournit une base technique pour créer et faire évoluer des applications Symfony et SvelteKit modulaires.

**Objectif :** démarrer avec un projet opérationnel, conserver un runtime simple et placer les fonctionnalités dans des modules.

## Lire en priorité

- [Principes](principes.md) : les règles qui guident les choix.
- [Composants](composants.md) : qui fait quoi.
- [Cycle de vie](cycle-de-vie.md) : de la création à la maintenance.
- [ADR](../adr/README.md) : les décisions structurantes.

Les commandes, options, formats et procédures détaillés relèvent de la documentation technique, pas de cette introduction.
